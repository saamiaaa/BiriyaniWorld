# BiriyaniWorld ‧₊˚ ⋅  𓐐𓎩 ‧₊˚ ⋅

**Biriyani World** is my first web development project, created in 2024 using HTML and CSS. It is a food-themed website homepage designed to introduce visitors to different varieties of biriyani and their cultural backgrounds. 

### 🛠️ Technologies Used
- HTML5
- CSS3

### 🎯 Project Purpose
This project was created as my first step into web development. It helped me understand the fundamentals of HTML and CSS, practice webpage structuring, and explore basic frontend design.
